# Записи пациентов

## Правила общения с пользователем
- Без предисловий, вступлений и заключений, сразу по делу.
- Не извиняться.
- Не излагать ход мыслей.
- Ёмко, без повторов.
- Короткие предложения и списки.
- Если ответ — одно слово или число, отвечать только им.
- Максимум 300 слов на ответ.
- Пользователь новичок: IT-термины объяснять коротко.

## Проект
- PWA для iPhone (ставится через Safari → «На экран „Домой“», работает без интернета). Брат пользователя — стоматолог, ведёт в нём записи пациентов.
- Весь код — `index.html`: чистый HTML/CSS/JS, без библиотек.
- Данные только на телефоне: localStorage, ключ `dent-v1` → `patients[]`, `appts[]`.
  Запись: `id`, `patientId`, `date` (YYYY-MM-DD), `time` (HH:MM), `dur` (мин), `service`, `note`, `status` (`planned` | `done` | `cancelled`).
- Настройки синхронизации — отдельный ключ `dent-sync` (`on`, `last`).
- `sw.js` кэширует файлы (stale-while-revalidate). Перед любым изменением `sw.js` повышать версию `CACHE`.
- Иконки `icon-*.png` сделаны из `icon.svg` через qlmanage и sips.
- Сайт: GitHub Pages https://mishaiua.github.io/zapisi/ (репозиторий github.com/mishaiua/zapisi, ветка `main`, push по SSH). Обновляется через 1–2 минуты после push.

## Синхронизация с календарём iPhone
- Через быструю команду «Записи». Приложение открывает
  `shortcuts://run-shortcut?name=Записи&input=text&text=<JSON>`.
- JSON: `{"events":[{"title","start":"YYYY-MM-DD HH:MM","end","notes"}]}` — все записи с сегодняшнего дня, кроме отменённых.
- Команда удаляет события календаря «Пациенты» с начала сегодняшнего дня и добавляет события из JSON (напоминание за час).
- Файл команды: `tools/make_shortcut.py` собирает plist → `shortcuts sign --mode anyone` → `zapisi.shortcut` в корне сайта.
- Нельзя: сервер, подписка webcal и любая передача имён пациентов в интернет — это медицинские данные.

## Mac пользователя
- Intel, macOS 14, без Homebrew и gh CLI, Python 3.13 с python.org.
- Пароли не вводить, ничего не оплачивать, системные настройки и безопасность не менять.
- «Быстрые команды» для computer use отображаются как «Команды»; без выданного доступа к экрану их окна не видны и не нажимаются.
